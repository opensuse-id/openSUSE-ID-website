Douglas DeMaio secara resmi telah mengumumkan openSUSE Asia Summit 2017 akan dilaksanakan di Tokyo pada tanggal 21 – 22 Oktober 2017 di laman resmi openSUSE.

[https://news.opensuse.org/2017/06/30/opensuse-asia-summit-2017-tokyo-japan/](https://news.opensuse.org/2017/06/30/opensuse-asia-summit-2017-tokyo-japan/)

Hari ini secara resmi juga panitia openSUSE Asia Summit 2017 telah mengumumkan pembukaan untuk pendaftaran bagi siapa saja yang ingin berpartisipasi sebagai pembicara atau membuat workshop pada acara tersebut.  Ada beberapa bentuk presentasi/workshop yang dapat dilakukan, yaitu :

* Long talk (30 menit + Q&A)
* Short talk (15 menit + Q&A)
* Workshop (120 menit)

Adapun untuk *Lighting Talk* juga akan diadakan kembali dalam durasi 5 menit, namun untuk pendaftarannya akan dibuka pada September mendatang. *Call for Paper* akan ditutup sampai tanggal 14 Agustus 2017, dan akan keputusan penerimaan materi akan diumumkan pada tanggal 4 September 2017.

Hal-hal apa saja yang bisa dijadikan bahan untuk *presentasi/workshop*? Sebenarnya segala hal yang berkaitan dengan **openSUSE** khususnya dan **open source / linux** secara umum bisa dijadikan bahan presentasi anda. Hal-hal di bawah bisa sebagai acuan:

1. openSUSE
   * Open Build Service, OpenQA
   * YaST
   * Linux kernel, File system, …
   * Virtualization and container
   * Embedded and IoT
   * Other software running on openSUSE
2. FLOSS Security
   * Access/Integrity control (e.g., AppArmor, IMA, Audit)
   * Cryptography
   * Vulnerability management
3. LibreOffice
   * Writer, Calc, Impress, …
   * Open Document Format
4. Linux Desktop
   * Desktop environments and applications
   * Graphics and multimedia
   * Multilingualization support (e.g., Input methods)

Selain itu, materi ***non teknis*** pun diperbolehkan seperti :

* Explanations of FLOSS technologies
* System operations
* Development, Quality Assurance, Translation
* Tips & Tricks, Experience stories (success or fail), Best practice
* Marketing and community management
* Education

Adapun langkah yang dilakukan untuk submit proposal, yaitu :

* Kunjungi laman [https://events.opensuse.org/](https://events.opensuse.org/)
* Kemudian login, jika belum punya silakan buat terlebih dahulu.
* Pada Events openSUSE.Asia Summit 2017, Pilih Submit proposal.
* Silakan submit proposal anda dengan Judul/*Title* dan menuliskan abstrak materi anda sekitar 120-500 kata, agar panitia dapat mendapatkan gambaran tentang materi yang akan anda submit.
* Judul dan abstrak yang anda berikan harus menggunakan Bahasa Inggris.

Setiap pembicara berhak mendapatkan subsidi/sponsor dari program openSUSE (Travel Support Program) sebesar 80% biaya akan ditanggung. Untuk informasi lebih lanjut terkait TSP silakan akses tautan berikut : [https://en.opensuse.org/openSUSE:Travel\_Support\_Program](https://en.opensuse.org/openSUSE:Travel_Support_Program)

Dan bagi anda yang hendak mendapatkan Travel Support Program dari openSUSE, mensubmit materi untuk long talk dan workshop sangat direkomendasikan. Ayo segera submit materi anda, masih ada cukup banyak waktu untuk mempersiapkannya. Anda bisa memasukkan lebih dari 1 materi supaya kesempatan anda terpilih makin besar. Sekarang saatnya anda tampil dan bicara di openSUSE.Asia Summit.

Sampai bertemu di Tokyo!
