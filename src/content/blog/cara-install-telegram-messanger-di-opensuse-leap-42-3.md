Untuk menginstall Telegram Messenger pada openSUSE Leap 42.3 ikuti langkah berikut ini:

1. Komputer harus terkoneksi internet
2. Download file [https://software.opensuse.org/ymp/home:bgta:desktop/openSUSE_Leap_42.3/telegram.ymp?base=openSUSE:Leap:42.3&query=telegram](https://software.opensuse.org/ymp/home:bgta:desktop/openSUSE_Leap_42.3/telegram.ymp?base=openSUSE:Leap:42.3&query=telegram)
3. Buka file tersebut dengan yast
4. Ikuti langkah-langkahnya sampai selesai
