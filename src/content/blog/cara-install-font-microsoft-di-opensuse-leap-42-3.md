Untuk menginstall font Microsoft di openSUSE 42.3 ikuti langkah berikut ini:

1. Download file berikut [https://software.opensuse.org/ymp/openSUSE:Leap:42.3:Update/standard/fetchmsttfonts.ymp?base=openSUSE:Leap:42.3&query=fetchmsttfonts](https://software.opensuse.org/ymp/openSUSE:Leap:42.3:Update/standard/fetchmsttfonts.ymp?base=openSUSE:Leap:42.3&query=fetchmsttfonts)
2. Buka file tersebut dengan menggunakan yast
3. Ikuti langkah-langkahnya sampai selesai
